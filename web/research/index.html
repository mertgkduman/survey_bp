Circuit integration

Stim workflow

Supported local adapter

Choose a cataloged Stim circuit, then export a package for local execution. The qualified adapter accepts independent-fault detector models using flooding SPA or min-sum with the float64 v1 numerical profile.

  • Detector and logical-observable semantics remain separate from CSS/Pauli recovery.
  • Damping, alternate resolution, and Relay policies are not circuit-adapter options.
  • Local execution records a ledger and reports unavailable metrics explicitly.

Local-first workflow

Getting started

  1. Browse cataloged papers, studies, evidence labels, and available result series.
  2. Inspect or adapt an exact specification; unsupported combinations stay visible as validation errors.
  3. Download the package, install this repository’s declared Python environment, and run python run.py locally.
  4. Keep the generated ledger, result summary, and copied specification together for review.
git clone git@github.com:mertgkduman/survey_bp.git
cd survey_bp
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[performance,circuit,analysis]'
.venv/bin/python -m bp_registry.research.cli serve --port 8765
# Open http://127.0.0.1:8765/web/research/
# In the downloaded package, using this same environment:
/path/to/survey_bp/.venv/bin/python run.py --repo /path/to/survey_bp --output ./results/run-001

A curve on this page is a retained catalog observation, not a new performance claim. Missing raw data is marked unavailable rather than linked speculatively.
