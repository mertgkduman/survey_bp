# Collecting while workers are active

The frozen automatic collector runs after all workers succeed. For a partial refresh during an active array, use:

```sh
PYTHONPATH=src OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  .planning/quick/261115-sxj-tune-canonical-beam-search-and-relaybp-a/collect_snapshot.py
```

This helper snapshots only workers with a complete receipt, verifies that receipt against the selection lock, then calls the unchanged frozen reference, full-ledger and endpoint audit helpers for every training and confirmation setting. It preserves the campaign's full planned count of218. The receipt names the snapshot scope and collector source hash. Active point files are excluded: they can acquire a fresh confirmation reference after a live reader has enumerated their references. An initial live partial collection caught that race and published no receipt or results. Production decoding and frozen source remain unchanged; no shot was rerun or discarded.

The `search` object in each concrete decoder configuration defines the complete search controller. Inherited binary seed-graph fields describe the original source BP graph; the explicit initial/per-unit caps, branch/leg budgets, solution count and memory controls in `search` govern execution. Reported work is always derived from the actual all-path event ledger.
