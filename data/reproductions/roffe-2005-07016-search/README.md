# Tuned beam search and RelayBP: Roffe X-only latency tradeoffs

This prospective controlled study uses all 109 original error rates across the four Roffe toric codes (lengths 162, 242, 338, 450), one CPU per method/rate. Both search methods decode the same X-only channel as canonical BP+OSD-0. These are CSS code-capacity adaptations of the [BeamSearch paper, Appendix B](https://arxiv.org/html/2512.07057v2) and [RelayBP paper, Sections II–V](https://arxiv.org/html/2506.01779v2), not reproductions of their circuit-noise curves. All old BP/Q-BP/OSD data remain immutable. No Pauli Q-BP search result is implied.

Every BP message update calls the unchanged canonical float64 min-sum sweep. Scaling is alpha_t*max(0,min_abs-beta), old-V2C damping is d, ties choose bit zero. Each segment restarts its paper scaling schedule and executes at least one sweep. Beam masks the least reliable unfixed variable by absolute accumulated posterior, branches 0 then 1, adjusts the original syndrome, inherits surviving edge messages, and prunes stably by descending mean accumulated reliability. Relay uses the dynamic prior (1-gamma)*channel_prior+gamma*previous_posterior each iteration; only posterior crosses legs, while V2C/C2V/damping histories reset. The first leg can use uniform memory. Later memory is uniform per variable/leg, using an indexed SplitMix64 public seed/shot/leg/variable stream shared across controls. This differs from the authors' RNG and is a declared adaptation. Dynamic effective priors alone are clipped at +/-1e6; every clip is counted. The original matrix always validates stopping; hidden truth reaches only the independent outcome evaluator. Multiple solutions select minimum original prior weight, with stable first-found ties; an initially converged beam run returns immediately as in the paper.

Prespecified finite tuning has three disjoint sample streams: coarse 2026111551, finalist 2026111552, fresh confirmation 2026111553. All same-stage candidates see matched physical prefixes; different error rates have independent counter identities. Coarse numeric grid: d in {0,.3,.5,.7}, scaling in {paper ramp*1,constant .75,constant1}, beta in {0,.25}. Anchor topology: 20 initial iterations, 20 per extra unit, 32 units, width2/depth8; Relay first gamma .125, later interval[-.24,.66]. Evaluate 512 shots each and retain the best two by LER, iterations, runtime, control digest among those below4.4x reference (fallback to all if none fit).

For Relay these two numeric settings first search first-gamma {0,.125,.35} and intervals {[-.24,.66],[-.5,.5],[-.25,1],[0,.75],[-.5,1]}; the best two advance to topology search. Relay topology grid: initial {10,40,80}, per-leg {10,30,60}, extra legs {4,16,64}, solutions {1,4}. Beam topology grid: initial {5,20,50}, per-branch {5,20,40}, width {1,4,16}, depth {4,12}, solutions {1,4}, branch cap min(512,2*width*depth). All anchor and intermediate settings remain eligible. Per-budget coarse winners receive axis neighbors in d(+/- .1), alpha(+/- .1), beta(+/- .125), bounded as in code; Relay also extends each interval endpoint by .1 within[-.75,1]. These are finite searches, not optimum claims.

For each mean-time budget .5/1/2/4 times BP+OSD-0, retain the best three coarse candidates under110% of that budget, or the fastest if none fit. Deduplicate and remeasure on at most65,536 independent finalist shots or100 failures, with a new reference. Select by minimum empirical finalist LER under110% of budget; ties prefer mean iterations, runtime, digest. If none fit, retain the fastest over-budget setting and label it. Freeze selection.json and its training hashes before fresh confirmation. This finite training can be unable to distinguish very rare errors; zero-failure training is not proof of equality. Selected configurations are deduplicated across budgets and each receives20 logical failures or100 million fresh shots. Every candidate and its tuning evidence stays available.

Reference timing is the median of five block means on1024 fixed shots, contemporaneously measured for the complete warmed undamped canonical BP+OSD-0 API at T=n on the same CPU. Its manifest and repeated timing events are retained. Search timing includes graph masking, initialization, disordered draws, all attempted branches/legs, pruning and selection. Both exclude sampling, truth evaluation, JIT, I/O and provenance hashing/serialization. Confirmation reports the measured ratio, rather than assuming calibration equality. p50/p95/p99 latency uses the upper edge of1%-wide logarithmic nanosecond bins (at most1% bin rounding error); tail timing is descriptive, not a hard real-time guarantee. Mean iterations sums every segment; directed edge updates sum actual masked edge counts, including pruned work. Exact failure-target/fixed-cap95% intervals use the existing audited stopping convention. All terminal failures remain in the denominator.

Each setting has a frozen manifest and compressed per-shot ledger; exact restart verifies hashes, chunk continuity and stopping. Only full-ledger/manifest/selection/endpoint-audited confirmations enter the result extension. Exact concrete controls form separate curves; singleton-rate policies can remain hidden by the workbench's central eligibility rule, while the report retains every point. Training is never pooled into LER. A50GiB storage guard preserves checkpoints. Production tasks request one CPU/2GiB for four days, separate native threads1 and job-local Numba caches; the dependent collector requests one CPU/16GiB. Partial or failed jobs never become complete measurements.
