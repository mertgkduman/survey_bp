# Joint BP numerical controls at BP+OSD0 runtime

This prospective controlled campaign preserves all previous paper-budget studies. It covers the same109 toric code/rate strata for binary BP(X-only) and joint Q-BP(depolarizing at1.5p_X), with one CPU per family/point. These channels remain distinct. Every message update delegates to existing canonical min-sum sweep functions, with float64 and original-syndrome stopping after at least one sweep.

The target is mean warmed decoder wall time per shot on the same CPU as a contemporaneous undamped canonical BP+OSD0 reference at T=n. It includes the complete OSD API when invoked and excludes sampling, truth evaluation, JIT and file I/O. Reference timing uses five repeats of1024 fixed calibration shots; the target is the median of the five per-shot block means. All repeated reference events, host/affinity and individual block means are retained. Absolute timings and actual reference ratios are reported; equality is never assumed.

Joint search: old-V2C damping d in{0,.3,.5,.7,.85}; scaling either the original alpha_t=1-2^-t schedule(multiplier1) or constant alpha in{.5,.75,1}; offset beta in{0,.25,.5,1} natural-LLR units. The canonical equation is alpha_t*max(0,min_abs-beta). The best two coarse candidates are refined in a local damping(+/- .1), scaling(+/- .1) and offset(+/- .125) grid, within the declared domains. This is a finite empirical search, not a global optimum claim. Zero damping is retained as a legitimate possible winner.

Each candidate starts at T=n. Increase caps by doubling until the runtime bracket is reached; retain every tested cap and LER. When the n-cap already exceeds the budget, record it and test lower caps explicitly rather than calling it matched. Four integer bisections refine timing brackets. Calibration tolerance is10%; iteration caps have an operational search guard of256*n, which is not a paper budget. Saturation when all calibration shots converge, lower-cap overhead and unmet budget at the guard remain visible. Calibration uses256 fixed shared shots, seed2026111421, and its LERs are tuning evidence only.

Recheck the best five coarse/refined candidates and the previous damping baseline on4096 fixed finalist-training shots(seed2026111422), with a fresh same-host reference and new cap brackets. This is a second tuning stage, not a claim of independent final LER. Select the smallest empirical finalist-training LER among configurations within110% of reference time; exact ties prefer lower mean executed iterations, then runtime. If none fit, preserve the fastest over-budget candidate and mark it honestly. Before fresh measurement, freeze each point's controls and confirmation caps. Both the previous damping settings(BP d=.5,Q-BP d=.3,paper scaling,zero offset) and joint selected settings receive an iteration progression including T=n, the matched cap, intermediate powers of two(or lower bracketing caps), and the first upper ladder cap as context. Identical concrete settings/caps are deduplicated. Training and confirmation are never pooled.

Fresh confirmation uses seed2026111423 and20 logical failures or100,000,000 shots per setting/cap, with exact stopping-aware95% intervals. Each confirmation retains mean executed iterations, directed edge updates, decoder time, reference time and ratio. Caps within a point use matched physical streams; independent per-cap stopping prefixes are not a simultaneous paired test. Resumes retain exact shot prefixes, original manifests, and per-shot reference receipt hashes. A50GiB free-space guard preserves checkpoints before filesystem exhaustion. Hardware changes are visible through reference receipts; observed confirmation timing ratios may differ from calibration and are never silently relabeled matched.

All tested tuning settings/caps and confirmation results appear in separate CSV tables. Only independent full-ledger/manifest/endpoint-audited confirmation enters the result extension. Curves are grouped by exact concrete policy/cap; the existing active-view rule may hide singleton error-rate curves. The dedicated study report preserves every point/cap regardless of that display rule.
