# Canonical BP profile and performance advance

Profiled setup, input validation, syndrome evaluation, and hot-loop execution on pinned BB72, HGP225, and GB46 workloads. The active Python BP4 kernel now preindexes incidence and computes each edge's quantized message once per sweep, reducing its median GB46 sweep from 337.7 to 125.9 ms with 20/20 before/after buffer hashes equal.

Added opt-in project-owned Numba prototypes for plain binary SPA/min-sum and four-state BP4, with fixed-prior binding for same-parameter shot batches. Warm compiled BB72 SPA took 0.308 ms/shot versus 201.2 ms for cached Python and 0.082 ms for `ldpc`; warm compiled GB46 BP4 took 0.587 ms/shot versus 607.3 ms for optimized Python and 0.201 ms for aSCED C++ on the eight early-stop cases. The [report](./REPORT.md) records timing scope, cold compilation, semantic mismatches, raw results, and the budget/ledger integration gate.

Differential verification compared intermediate buffers and terminal decisions. The relevant suite passed **197 tests**. Native min-sum zero/near-zero ties and aSCED fixed-sweep recurrence differences remain explicitly unresolved; the compiled prototypes are not selected by production manifests.
