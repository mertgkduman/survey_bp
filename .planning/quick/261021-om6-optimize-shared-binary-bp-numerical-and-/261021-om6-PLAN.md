# Optimize shared binary BP execution

Goal: reduce work in the production binary numerical and flooding path while preserving the existing numerical profile, policy callbacks, work counts, and replayable traces.

1. Pin before-change box-plus output bytes and BB72 sweep traces/timings for SPA, min-sum, normalized min-sum, and offset min-sum.
2. Preindex immutable flooding exclusions and avoid redundant snapshot copies. Evaluate a scalar box-plus implementation only if its output bytes and failure semantics match the current numerical profile; otherwise leave that primitive intact.
3. Compare before/after numerical buffers and evidence, run binary policy, schedule, memory, and replay tests, and record measured effects and limits.
