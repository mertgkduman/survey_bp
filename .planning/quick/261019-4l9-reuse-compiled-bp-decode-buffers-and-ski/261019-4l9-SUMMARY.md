# Compiled decode buffer reuse

Implemented reusable private iteration scratch for optional compiled binary and BP4 plain decode. The BP4 public sweep still computes marginals while its candidate-only decode path skips them. Matched same-core medians show BB72 SPA 0.30904 → 0.26696 ms/shot and GB46 early-stop BP4 0.59890 → 0.58697 ms/shot; BB72 min-sum is 0.04189 → 0.04271 ms/shot. Candidate hashes, iterations, and convergence are unchanged for every retained case. Eleven focused differential tests pass. See `REPORT.md` and the raw JSON timings for conditions and limits.
