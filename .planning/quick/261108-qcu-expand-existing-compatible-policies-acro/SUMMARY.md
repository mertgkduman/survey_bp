# Compatible policy expansion

Implemented a shared, opt-in binary execution contract for CPU code-capacity
and Stim/Sinter fault graphs. Both transports execute the existing canonical
policy machinery with owned heterogeneous priors and replayable work/lineage
evidence. Historical interfaces, defaults and scientific gates remain intact.

The user explicitly chose **existing/source-defined counterparts only**. No
generic binary-memory or intervention recurrence was invented for Pauli BP.
The existing Pauli counterparts and qualified GPU subset remain available;
their exclusions and required operands are recorded in the executable inventory.

## Delivered

- Owned vector priors in binary sessions, fresh resets, impulse/shortening,
  freezing, syndrome flip, sign flip, Restart Belief, MBBP and fair-leg beam
  execution. Surviving coordinates retain their own channel priors.
- `BinaryPolicyDecoder` and `SharedPolicySinterDecoder`: six schedules, five
  ordinary memory policies and nine controllers, including disordered memory,
  supported intervention damping and existing MBBP list/voting.
- Explicit scalar/source-iteration/check/edge NMS/OMS assignments and generated
  configuration/attempt/source-iteration coefficients, preserving canonical IDs.
- Compiled ordinary flooding and vector-prior execution of the existing v2/v3
  precision policies: six message formats, damping, alpha/beta and coefficient
  rounding. These retain float64 storage/arithmetic, not native low-bit speed.
- Sparse ordinary graph setup, cached CSR indexes and validated static controls;
  mutable schedule, generator, memory and controller state remains shot-local.
- Packed Sinter I/O, affine observable projection, original detector validation,
  complete controller receipts, immutable outputs and exact ledger replay.
- Explicit admission errors for unsupported combinations, inactive controls,
  missing graph operands and ambiguous Relay memory order.

Usage and boundaries: [shared-policy-support.md](../../../docs/shared-policy-support.md).
Machine-readable inventory: [capabilities.json](capabilities.json), generated by
`bp_registry.policy_capabilities.capability_inventory()`.

## Scope decisions

Pauli MBP4, Q-BPGD, C2V transforms and CSS-qualified aSCED retain their own
mathematical contracts. A binary DEM does not supply their four-state variables
or splitter operands. Optional SI/OTF source/operand restrictions remain in
place. Clustered learning has an artifact gate, not an implemented scheduler;
it is not relabelled as a runnable policy. These are documented limitations.

GPU source and joint-Pauli source are unchanged. No new GPU qualification is
claimed. Historical campaigns were neither rerun nor reinterpreted, release
packaging remains outside scope, and Phase 11 publication gaps, Phase 5 human
review and paused Phase 7 work remain unchanged.
