# Damping tuning, then an early BP-OSD baseline study

GSD quick workflow with research and validation performed inline. User authorizes
new simulations, canonical-kernel reproduction and GitHub publication. Preserve
all existing kernels, frozen plans, raw evidence and archived v1. Do not modify
model settings. Scientific phase gates stay separate from these requested studies.

1. Check and publish final MacKay paper-rate evidence. Verify frozen pins,
   collector state, the newly added receipt and preservation of previous records.
   Record full counts and pointwise source comparisons without claiming agreement
   when a source ordinate lies outside its interval.
2. Freeze a damping sweep for ordinary binary SP and joint Q-BP SP on both
   MacKay codes, at the five paper rates / matched depolarizing rates, retaining
   88,200 total iterations. Define damping as old-message weight. Use new seeds,
   a prespecified grid, objective and uncertainty-aware tie rule; retain all
   candidates and separate tuning from fresh confirmation evidence. Primary
   objective is block LER, secondary is mean actual total iterations, with mean
   directed edge updates also retained. Never infer equivalence from overlapping
   intervals. An inconclusive comparison must stay inconclusive.
3. Select an early primary BP-OSD paper with an explicit standalone BP curve.
   Pin paper revision, exact codes, measured rates, check rule, normalization,
   schedule, prior and iteration budget. Reproduce regular BP using existing
   canonical sweeps. Add Q-BP at the same total-iteration ceiling and matched
   marginal depolarizing rates, marked as a controlled comparison. No new OSD
   implementation is requested. Use paper settings even if different from MacKay.
4. Qualify algebra, policies, iteration/edge counters, stopping, resume, endpoint
   replay, independent outcomes and source extraction. Freeze every compute
   artifact before submission. Keep worker concurrency bounded and record Slurm
   receipts. Sequence the new-paper compute after damping confirmation, while
   doing independent source preparation now. Automatic collectors audit terminal
   evidence and publish through the common multi-rate catalog projection.
5. Verify catalog/browser selection, exports, empty/stale state and preservation.
   Update research, verification, summary and STATE records, commit and push.
   Running simulations must remain explicitly open with an executable continuation.
