# First CSS literature policy gate

## Decision

Start a small literature-policy gate during Phase 6, then add further papers while bounded simulations run alongside implementation. Preserve the roadmap's CSS code-capacity, correlated quaternary, then circuit-level sequence. A paper decoder TOML sits directly in `literature_policies/<paper-id>/`; code, noise, circuit, source results, and eventual reproduction manifests sit in `paper_reproduction/`.

The TOML must contain the **kernel-readable policy composition** and parameters. Structured source identity, equation anchors, and explanations may live in the same file as non-executable metadata. A parser resolves only registered, compatible policy kinds into the effective execution manifest; it preserves metadata as provenance and rejects unsupported controls. Changing commentary alone must not change the numerical execution identity, while the provenance revision remains traceable. Equations in prose never execute as code.

These sources all name B1. That name alone does not prove identical ordered check matrices or logical bases. The repository's Panteleev–Kalachev B1 v3 artifact is a candidate input; each paper's experimental artifact identity must be reconciled before a source-faithful curve claim.

## Gate and simulation cadence

1. Inventory every requested variant in a source-grounded `.spec.toml` and record explicit blockers. Convert to runnable `.toml` only after registered policy preflight and independent equation/control-flow checks.
2. Demonstrate the same public command on a small identified CSS study with at least one qualified variant from each paper. All requested variants must either preflight or return a typed compatibility/unsupported status. The gate includes verified shot ledgers and original-problem checks, not agreement with a full published curve.
3. While other code work continues, run bounded mechanism pilots. Freeze separate parameter-selection and evaluation samples, work limits, stopping/denominator rules, and statistical targets before any larger assessment. Retain inconclusive and failed runs.
4. Keep paper-specific reproduction and controlled cross-paper adaptations distinct. Cross-testing may reuse decoder TOML on a shared B1 or BB study, but must not inherit a paper's reproduction label or use a different kernel without an explicit adaptation identity.
5. Phases 8–9 retain ownership of general campaign machinery and publication-level CSS curve assessment. Quaternary and circuit targets follow their existing phases.
