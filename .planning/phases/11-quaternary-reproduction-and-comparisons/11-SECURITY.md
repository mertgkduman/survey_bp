# Phase 11 — Security

## Trust Boundaries

| Plan | Boundary | Description |
|---|---|---|
| 11-01 | paper image and extraction evidence to target receipt | Human-interpreted plotted values become assessment inputs only after complete digest-bound calibration and review. |
| 11-01 | target receipt to source manifest | Frozen settings, tolerance, and stopping authorize later sampling. |

| 11-04 | pinned external source to proposal generator | Untrusted source bytes are verified before analysis or diff creation. |
| 11-04 | unapplied diff to human authorization | A derivative proposal could change algorithm meaning or rights scope if applied. |

| 11-08 | design artifact to statistics | Prespecified rows and estimands constrain all later calculations. |
| 11-08 | matched records to cross-point inference | Disjoint physical samples enter one simultaneous family. |
| 11-09 | public CLI to output root | Untrusted manifests request deterministic compute and durable evidence writes. |
| 11-09 | shard set to merged assessment | Independently produced shard receipts become one statistical dataset. |
| 11-10 | code artifact to controlled runner | BB72 provenance and logical metadata constrain valid evaluation. |
| 11-10 | calibration evidence to resource proposal | Bounded measurements are extrapolated to larger immutable campaigns. |
| 11-10 | site evidence to authorization receipt | External scheduler/accounting facts determine whether any production dispatch may occur. |
| 11-11 | measured package to human decision | Scientific eligibility and external site/accounting evidence become permission for costly dispatch. |
| 11-12 | authorization/qualification to execution | External permission and source identity determine whether exact compute may run. |
| 11-12 | raw source outputs to assessments | Counts and traces become discrepancy verdicts and claims. |
| 11-13 | source qualification to policy manifest | Published method details authorize only specific executable configuration changes. |
| 11-13 | shared sample to multiple methods | One physical error is exposed to methods with different permitted inputs and work semantics. |
| 11-14 | retained results to final index | Independently produced source, controlled, and policy artifacts become public conclusions. |
| 11-14 | installed verifier to filesystem | Untrusted paths and serialized evidence are resolved and recomputed. |
| 11-15 | sealed authorization to conditional runner | A human-reviewed digest allowlist and external site/accounting facts become permission for costly controlled execution. |
| 11-15 | scheduler and shard outputs to code receipt | External job states, partial attempts, ledgers, and resource accounting become durable evaluation evidence. |
| 11-15 | calibration and evaluation evidence | Bounded profiling informs forecasts but cannot supply controlled evaluation samples or scientific results. |
