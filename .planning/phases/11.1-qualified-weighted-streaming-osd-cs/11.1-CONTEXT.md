# Weighted, bounded-memory OSD qualification

## Domain

Implement all four requirements in the user's 2026-11-17 request. This is a
scoped autonomous insertion, independently executable on the already-qualified
canonical BP/OSD foundation; it does not close unrelated Phase 7/11 gates.

## Decisions

- Preserve frozen `postprocessing/osd.py`, running campaigns and historical receipts.
  Add an explicitly selected v2 processor. Preserve signed stable LLR ordering,
  OSD0's syndrome-dependent partial elimination, singles then lexicographic pairs,
  and strict first-minimum selection.
- Cache original-channel weights. Default nonuniform score is the pinned native
  `sum(log(1/p_i))`; expose Bernoulli log-odds separately and qualify both. Uniform
  positive weights use the existing integer Hamming/popcount score and digest.
- Accept dense/CSR/CSC binary matrices without retaining a redundant dense H.
  Profile sparse versus packed storage/validation; GF2 elimination may fill in.
- Bounded, opt-in exact-matrix/exact-column-order affine cache; record cold cost,
  misses, hits and bytes. Never reuse syndrome-dependent OSD0 factors.
- Full and fast evidence are explicitly versioned. Both retain candidate order,
  weights, streaming candidate-then-weight digest, input identities, selected
  candidate, mandatory work ledger and deterministic replay. Materialization is
  optional. Full additionally validates every candidate against original H.
- Qualify against an independent per-candidate GF2 solve and weighted scoring;
  exact finite float64 original-index accumulation, no fastmath or reassociation.
- Benchmarks use matched inputs and alternating warmed variants, one allocated
  CPU, separate cold/JIT/constructor cost, fresh-process peak RSS and tracemalloc,
  actual canonical BP nonconvergence and whole BP+OSD timing. No blanket speed claim.
