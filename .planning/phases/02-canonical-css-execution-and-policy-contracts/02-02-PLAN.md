**As a** QLDPC researcher, **I want to** run and inspect a project-owned canonical CSS BP policy composition, **so that** decoder behavior, outcomes, and computational work are trustworthy and comparable.

<objective>

Output: Strict persisted composition dispatch, closed runtime registry, typed lifecycle/capability/decision objects, and source-linked policy evidence.
</objective>
