<threat_model>

| Boundary | Description |
|----------|-------------|
| persisted numerical terminal -> verifier replay | A valid recorded failure must remain auditable even when the same arithmetic defect prevents deterministic replay. |
| attacker-rehashed event stream -> PublicShotContext | Public hashes establish integrity, not truth; statuses, lineage, and manifest provenance require trusted reconstruction. |
| profiler raw source fact -> normalized RSS claim | Platform units determine the only valid raw-to-byte relationship. |
| validated stream -> checked result | Only terminal evidence that passes every terminal-class and provenance invariant may support reuse or result verification. |
