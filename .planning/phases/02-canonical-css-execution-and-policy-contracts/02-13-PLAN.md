<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| preflighted experiment -> replay key | Full manifest, code/artifact, sample, run, and shot identity must govern reuse. |
| persisted JSONL -> scientific evidence | Valid JSON and event hashes are untrusted until deterministic structural claims are reconstructed. |
| profile/trace controls -> public execution | Unbounded or unsupported observation plans fail before work; admitted evidence is typed. |
| validated terminals -> result.json | Only structurally approved terminal objects may determine public counts and labels. |
