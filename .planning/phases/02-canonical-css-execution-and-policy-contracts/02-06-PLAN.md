## Phase Goal

**As a** QLDPC researcher, **I want to** run and inspect a project-owned canonical CSS BP policy composition, **so that** decoder behavior, outcomes, and computational work are trustworthy and comparable.

<objective>
Make native-reference instrumentation missingness interoperable with canonical work evidence without fabricating comparability.

Purpose: The canonical engine can count internal work exactly, while opaque native adapters cannot; reporting unavailable native counters as zero or inferred fact would corrupt comparisons.
Output: Typed metric missingness and native ledger/query regressions.
</objective>
