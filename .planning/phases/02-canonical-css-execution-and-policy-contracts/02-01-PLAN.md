## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest/artifact → canonical execution | Strict untrusted persisted input enters numerical execution. |
| sampler/runner → policy engine → evaluator | Decoder-visible observation must remain separated from hidden truth and post-selection evaluation. |
| execution → JSONL ledger | One logical shot becomes durable evidence under ownership and content identity. |

</threat_model>
