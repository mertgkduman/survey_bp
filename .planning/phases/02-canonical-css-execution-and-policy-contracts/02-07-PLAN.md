## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process/machine profiler → durable evidence | OS/runtime measurements and environment context are collected. |
| cohort selector → population claims | Selected representative or diagnostic runs acquire distinct statistical meanings. |
| clean execution → profiled replay | Instrumentation may perturb semantics and runtime. |

| T-02-26 | Tampering | profiled replay semantics | high | mitigate | Link deterministic identities and compare candidate/termination/work/lineage/semantic digest before accepting a paired measurement. |
