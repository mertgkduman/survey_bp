| Campaign JSON to frozen plan | Untrusted paths, hashes, counts, and arm definitions become bounded scientific work only after strict validation. |

| Materialized sample to canonical engine | One verified observation is replayed through each arm while hidden truth remains evaluator-only. |
| Canonical evidence to merge/report | Only independently replayed immutable attempt bytes can contribute a terminal or denominator. |
