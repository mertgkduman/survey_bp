# BB-144 lower-noise LER campaign handoff

The user requested lower physical error rates and a precision-driven estimate of each decoder's error rate, then specified four diagnostic proposal categories: valid syndrome/correct logical projection, valid syndrome/wrong logical projection, invalid syndrome/correct logical projection, and invalid syndrome/wrong logical projection. A missing proposal remains a fifth explicit category. The user chose to count no recovery as an all-shot failure.

This independent experiment runs on branch `gsd/phase04-low-noise-ler`, commit `e943a22`, in `/hpc/group/pfisterlab/mg551/storage/survey_bp_low_noise_20260925`. It is isolated because changing the canonical ledger while the main active-V4 timing campaign is running would invalidate that campaign. Do not merge the branch into the main checkout until the active-V4 benchmark has reached a terminal report. Do not delete the worktree while the lower-noise job is running.

Bonferroni adjustment covers the six looks and two precision metrics per arm/rate. The campaign has a five-day internal wall cap; unmet precision is retained as inconclusive.
