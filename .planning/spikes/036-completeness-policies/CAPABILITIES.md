## A durable extension contract

Admission should resolve a tuple of **regime, family, prior representation, update rule/assignment shape, numerical version, schedule, memory, controller and backend** into one frozen execution contract. It should include:

1. Required operands and their shapes, canonical edge/variable maps, original-space lift and graph identity.
2. Named callback/update order, exact iteration/local-unit context, retained history, reset/clone/fork/commit boundaries and RNG scope.
3. Quantization, clipping, ties, unary/empty-check conventions, nonfinite-state failure, stopping and effective coefficients.
4. Candidate construction, original-problem validation, optional logical evaluation, work reservation and emitted evidence.
5. Source fidelity and version, compatible combinations, explicit exclusions and independently checked acceptance cases.

Derive constructor rejection tests and UI availability from that contract. Retain separate independent numerical oracles: generating both execution and its expected numerical answer from the same registry would not test mathematics. Every new policy needs an identity case where one exists, a parameter-sensitivity case, an order-sensitive case, and failure/denial/reset cases. Boundary matrices should test every accepted assignment shape and backend, with targeted interaction coverage instead of claiming an untested Cartesian product.

This consolidation is a design recommendation, not work silently completed by this audit.

## Covered and deliberately unresolved axes

The 432-row `grid/matrix.json` is the executable compiled subset. Existing scalar/controller regressions and the negative admission receipts supply other cells, with different strength of evidence. There is no claim that all permutations of listed capabilities are valid. In particular, heterogeneous compiled binary binding, general zero-mass Pauli channels, generic compiled custom callbacks, arbitrary adaptive memory/controller combinations, differentiable learning and fully integrated stable-policy circuit execution remain unqualified or absent. Source-faithful reproduction, controlled performance comparison and mere API admission are separate qualification states.
