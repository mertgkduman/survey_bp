# Hsu non-disjoint group-shuffled BP: binary CSS adaptation

Source: Hsu, Chang, Su, and Weng, [*A Non-Disjoint Group Shuffled Decoding for LDPC Codes*](https://arxiv.org/html/1202.1060), arXiv:1202.1060v1, Section II. The source studies classical LDPC codeword decoding over BI-AWGN. This project uses its message-update schedule on a binary CSS syndrome problem and labels results `pilot_adaptation` / `not_assessed` until a separate reproduction target is qualified.

The supported source configuration is the paper's worked group size 2 and overlap 1. Each source iteration samples an ordered permutation of check IDs using a dedicated schedule RNG. Consecutive pairs form the groups: an order `(c1,c2,c3,c4)` gives `(c1,c2)`, `(c2,c3)`, `(c3,c4)`. All checks occur; interior checks occur twice. The general parameter notation in the source is inconsistent, so no other group size or overlap is claimed. Record the root and derived RNG identities, NumPy/PCG64 version, sampled permutation, realized groups, source iteration, and exact membership multiplicity. Physical-error samples use a different RNG stream.

For each group, compute both check-to-variable message sets from the same group-entry variable-to-check snapshot. Commit them, then refresh variable-to-check messages incident to either check's neighboring variables before proceeding to the next group. The source tests its hard decision after a whole traversal. Project decision D-09 tests after every committed group instead; the ledger must identify that stopping adaptation. One group and its convergence check form the atomic budget unit. Repeated checks count as repeated message updates. Setup and decoding time remain separate.

The checks in one Hsu group may share variable neighbors. The canonical `LayeredSchedule` rejects such groups, so this is a distinct policy on the same binary BP engine. The decoder never sees hidden simulation truth; independent evaluation uses the original syndrome and code. This policy does not implement Moradi clustered RL-S, which remains unavailable without its author Q-table and partition, and no classical AWGN performance curve is claimed for the CSS adaptation.
